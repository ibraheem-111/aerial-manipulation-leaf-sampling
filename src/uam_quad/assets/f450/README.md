# DJI F450 meshes

Converted from the CTU Multi-robot Systems group's Gazebo model
(github.com/ctu-mrs/mrs_uav_gazebo_simulator, `models/mrs_robots_description/meshes/dji/f450/`),
BSD 3-Clause License, Copyright (c) 2023 Multi-robot Systems (MRS) group at Czech Technical
University in Prague. COLLADA files were converted to OBJ in meters (the `<unit>` scale applied;
one unescaped `&` in `dji_f450_rotor.dae` was escaped). Visual only; collisions use primitives.
Physical parameters come from the same repo's `sdf/drones/f450.sdf.jinja` (see `f450_mrs()`).
