# Practice: running MuJoCo yourself

- `COMMANDS.md`: every command for looking at the model, flying it, rerunning the experiments, plus a 5-minute live-demo script.
- `exercises.py` + `check.py`: 12 hands-on exercises, graded automatically:
  `source setup/env.sh && cd practice && python check.py` (from the repo root)
  (`python check.py 3` grades only exercise 3; `--solutions` grades the reference answers.)
- `solutions.py`: worked answers. Try first.
- `QUESTIONS.md`: questions Das is likely to ask, with short answers to say out loud.
